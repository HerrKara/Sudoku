# Sudoku (privat, ohne Werbung)

Offline-fähige Web-App (PWA). Öffnen: `index.html` im Browser, oder per GitHub Pages hosten und auf dem Handy "Zum Startbildschirm hinzufügen".

- 5 Schwierigkeitsgrade (Anfänger → Experte), nach benötigter Löse-Technik bewertet, jedes Rätsel eindeutig lösbar
- Notizen, Auto-Notizen, Rückgängig, Tipps mit Erklärung, Fehleranzeige, Pause
- Statistik (Siege, Bestzeit, Durchschnitt), Spielstand wird automatisch gespeichert
- Dunkelmodus, Tastatursteuerung (1-9, N, Z, H, Pfeile)
